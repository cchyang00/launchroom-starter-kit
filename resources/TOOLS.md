**No passwords here.** The owner signs in once in the shared browser (the Claude desktop app's browser pane or their own Chrome); agents work in that signed-in session and never type credentials. When a tool shows a sign-in wall, stop and ask the owner to sign in again; never type a password.

Claude Code: `node .claude/skills/merrivy-os/scripts/os.mjs tools --step find` lists the tools for a step; `os.mjs tool <id>` prints one tool's link and notes, then open that link in the browser pane.
