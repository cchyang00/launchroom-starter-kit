## The memory habit

1. Before a job: read the brief (this page, for the manager).
2. After a job: write one diary line (what happened), then answer "what should we do differently next time?" Propose a lesson or say "nothing new", and record which lessons helped.
3. Knowledge lives in the Library (resources/LIBRARY.md): search it before researching from scratch (`os.mjs library search "topic"`) and write what you learn back (`library note` or `library done K-###`).
4. The manager checks proposals after every job and reviews the lesson list weekly. memory/STATE.md, memory/JOURNAL.md (except real decisions) and the role STATE/LESSONS files are archived history as of October 1, 2026.
