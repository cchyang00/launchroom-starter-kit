Kalodata can be delegated in parallel only if a separate supported authenticated session is actually available. Otherwise the Luxury operator performs the UI captures and a specialist can analyze the saved evidence. A new agent does not create another browser session. The manager may also be the Luxury operator; a separate manager agent is unnecessary for that allocation.

## Early visual lead card — brief, one per survivor

For the current Kalodata pilot, use the same identity, visual, buyer and exclusion fields, but record the exact Kalodata listing/shop URL and ID, actual country/window, observed price and masked metric limits instead of ad IDs/impressions. Do not fill absent Pipiads fields or imply the listing's total sales belong to a particular video. The Pipiads-specific rows below apply only when that surface was actually inspected.

| Field | Observed value / evidence |
| --- | --- |
| Lead ID and exact item | Family, variant, included parts and defining physical feature |
| Source links | Exact ad ID/URL, original post, merchant product, discovery country |
| Visual | Saved actual frame + demonstrated moment/timecode; staging/AI/identity uncertainty |
| Buyer reason | Visible feature → specific situation → desired outcome; hypothesis versus actual comment evidence |
| Other buying reason | Distinct reason worth checking, or unknown; do not invent a second persona |
| Exclusion check | Cheap retail / recognizable brand dependence / generic / prop / unsuitable fulfillment; controlling failure if any |
| Prices | Displayed currency, variant/quantity; merchant delivered retail; not our acquisition cost |
| Ad signals | Exact labels, date window, creation/first/last seen and run-time meaning; estimated metrics remain estimates |
| Next decision | One specific uncertainty for source preflight; unsupported items remain provisional/PARK |

Ordinary rejects need only source link, identity and decisive reason. Aim for 10–20 distinct credible leads in an authorized discovery assignment, but report the real shortfall rather than padding. Those leads are not ten verified winners. Source-feasible survivors can be handed onward incrementally; do not wait for an arbitrary quota before processing useful evidence.

## Source preflight — before detailed Kalodata work

- Exact defining feature/variant/contents matched? Evidence and mismatch, if any.
- Repeat quantity-one route, listing URL, ordinary acquisition price and destination freight/bound; stock/handling uncertainty. Retail listing or inquiry form alone is insufficient.
- Competing delivered retail price versus our evidenced repeat landed acquisition, recorded separately.
- Base single-item pre-ad contribution = customer receipts excluding collected tax, less discounts, landed goods/freight, fees and explicitly assumed refund/defect allowance. Missing costs stay unknown.
- Optional acquisition-cost ceiling = receipts minus other variable costs minus **assumed** acquisition allowance and contribution reserve. This is a planning bound, not an observed supplier cost or a proven Meta CAC.
- Result: feasible preliminary route / unresolved / decisive fail, with evidence and reopening condition. Quote, sample and final delivery remain later gates. No unsolicited supplier contact.

## Kalodata return — matched evidence, not a new product

- Input lead ID/source-feasibility record; exact Kalodata product/shop IDs and original listing.
- Match: same / materially different / uncertain. Compare physical feature, variant, pack size, price context and destination.
- Last complete date; 30-day scope and available older history; each missing day explicitly identified.
- Latest seven complete days versus previous seven: units, revenue, observed/calculated ASP and changes; daily shape, promotions/stockouts and low baseline.
- Contributor counts, largest creator share and largest video/live share only with aligned definitions/denominators; overlapping buckets never summed.
- Distinct original demonstrations and meaningful buyer evidence; seller/affiliate/paid context and reused-footage limits.
- Supporting evidence, strongest counterevidence, missing definitions/access, decision and next action.
- Evidence source/date/type on every material result; source rows or screenshots preserved.

The manager accepts the return only when scope, IDs, denominators and unknowns reconcile with the input. Kalodata completion cannot pass source quality, Meta competition, owner selection, final procurement or launch. Five complete comparable reviews remain the selection minimum under the parent contract.
