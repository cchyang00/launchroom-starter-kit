# Specialist Registry & Operating Contract (Updated November 5, 2026)

The working Merrivy team is the **8 specialist subagents** in `.claude/agents/*.md`, indexed in [team.json](team.json) and displayed in the **Subagents & Skills Hub (`#/agents`)**. Every subagent inherits the primary model (`inherit` / `opus`) and starts every job by reading its Launchroom brief (`node .claude/skills/merrivy-os/scripts/os.mjs brief --agent <id>`).

The parent [AGENTS.md](../AGENTS.md) owns shared authority, workflow gates, and owner communication. **The main conversation acts strictly as the Manager / Dispatcher** — whenever the owner sends a task in chat, the chat spawns the appropriate specialist subagent(s) to execute the work rather than running heavy jobs directly in the main chat.
